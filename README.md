# mangen

`mangen` — консольная утилита на C для создания манифеста каталога. Она
рекурсивно обходит каталог, вычисляет SHA-256 для файлов и выводит пары
«относительный путь — хэш» в стандартный поток вывода.

Репозиторий: [github.com/Knoukl/safeboard-intern-c-2026](https://github.com/Knoukl/safeboard-intern-c-2026).

Пример строки манифеста:

```text
level1/notes.txt : <64 hex-символа SHA-256>
```

Если путь к каталогу не указан, утилита обрабатывает текущий каталог.

## Сборка и запуск

Для сборки нужны GNU Make и GCC:

```sh
make all
```

Готовая программа появится в `build/mangen`. Запуск:

```sh
./build/mangen [DIR_PATH] [OPTIONS]
```

Примеры:

```sh
./build/mangen src/tests/example
./build/mangen src/tests/example -e 'skip*end'
```

## Опции

- `-h` — вывести справку.
- `-v` — вывести Git commit hash, встроенный при сборке.
- `-e PATTERN` — исключить записи, имя которых совпадает с шаблоном. Сравнивается
  имя файла или каталога без пути: `.` соответствует одному символу, `*` —
  любой последовательности символов, включая пустую. Если совпал каталог,
  утилита не обходит и его содержимое.

Опции `-h` и `-v` можно указать вместе. Опцию `-e` можно указать один раз.
Ошибки выводятся в `stderr`.

## Как обрабатываются записи

Обычные файлы хэшируются алгоритмом SHA-256, реализованным в проекте. Ссылка на
обычный файл попадает в манифест под именем ссылки; ссылка на каталог и другие
специальные типы объектов пропускаются. Ошибка при чтении каталога, файла или
цели ссылки выводится текстом.

В реализации обхода каталогов используются POSIX-функции. Во время работы
утилита не запускает внешние программы для вычисления хэшей.

Проект разрабатывался и проверялся в Linux. При обходе учитываются типы
файловых объектов, используемые в Linux/POSIX: обычные файлы, каталоги,
символические ссылки и специальные объекты вроде FIFO. Специальные объекты
пропускаются.

## Тесты

Для запуска тестов нужны Check (`check.h`), `pkg-config`, `lcov` и `gcov`:

```sh
make test
```

Цель создаёт тестовое дерево в `src/tests/example` с вложенными каталогами,
файлами, символическими ссылками и FIFO, запускает тесты и формирует отчёт о
покрытии строк. `make test` завершится ошибкой, если покрытие ниже 80%.

Удалить собранную программу, тестовые артефакты и созданное тестовое дерево:

```sh
make clean
```
